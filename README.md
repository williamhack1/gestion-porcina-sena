# Sistema de Gestion Porcina - Modulos de Software

Modulo de software desarrollado con **Node.js + Express + MySQL (mysql2)** para las evidencias:
- **GA7-220501096-AA2-EV01** - Codificacion de modulos del software (API REST + CRUD).
- **GA7-220501096-AA2-EV02** - Modulos de software codificados y probados
  (formularios HTML + metodos GET/POST + motor de plantillas EJS).

El proyecto expone un CRUD completo para la entidad **Cerdos**, sirve el frontend
(HTML/CSS) desde `public/` y ofrece vistas renderizadas en el servidor con **EJS**.
